# Notes

An offline-first notes app for Android, published on APKPure.

Organize thoughts, ideas and to-do lists with custom note colors and a
comfortable dark mode. Create, edit, search and categorize notes - all data
stays on the device, no account needed.

## Features

- Full CRUD with search and color-coded categories
- Dark mode
- Offline-first local storage - works with no connection

## Tech Stack

Flutter - Dart - BLoC/Cubit (flutter_bloc) - Hive (local NoSQL storage) - intl
